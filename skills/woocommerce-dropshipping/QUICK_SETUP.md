# ⚡ Shopzario Quick Setup Card

## 🎯 5-MINUTE SETUP

### 1. Import Template (1 min)
```
Elementor → My Templates → Import
Upload: /tmp/shopzario-elementor-homepage.json
```

### 2. Add Custom CSS (1 min)
```
Appearance → Customize → Additional CSS
Copy from: shopzario-custom.css
```

### 3. Set Fonts (1 min)
```
Elementor → Settings → Global
Headings: Poppins
Body: Inter
```

### 4. Set Colors (1 min)
```
Primary: #FF6B6B (Coral)
Secondary: #4ECDC4 (Teal)
Accent: #FFE66D (Yellow)
```

### 5. Import Products (1 min)
```
cd /root/.openclaw/workspace/skills/woocommerce-dropshipping/scripts
python3 multi_supplier_import.py
```
